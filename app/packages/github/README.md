# @musichen/justtuit

> GitHub Packages mirror of [justtuit](https://www.npmjs.com/package/justtuit) - a TUI for TUI tools.

**justtuit** is a cross-platform terminal UI that catalogs **672 terminal apps
across 13 categories** and turns them into install commands for your platform's
package manager.

## Install (from GitHub Packages)

```bash
# configure the GitHub Packages npm registry for the @musichen scope
echo '@musichen:registry=https://npm.pkg.github.com/' >> ~/.npmrc
npm install -g @musichen/justtuit
```

This package depends on the unscoped `justtuit` (from npmjs.org) and exposes the
same `justtuit` binary.
